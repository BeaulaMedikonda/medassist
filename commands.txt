MedAssist common commands
=========================

Run project
-----------
cd C:\Users\yamin\Downloads\ProjectDoctor\ProjectDoctor\MedAssist
npm install
npm run dev

Open:
http://localhost:3000

If port 3000 is busy:
npm run dev -- -p 3001

Open:
http://localhost:3001


Check project
-------------
npm run typecheck
npm run lint


FHIR validator
--------------
Start Docker validator:
npm run fhir:validator:up

Run strict FHIR validation:
npm run fhir:validate:strict

View validator logs:
npm run fhir:validator:logs

Stop Docker validator:
npm run fhir:validator:down

Direct Docker commands:
docker compose up -d --build fhir-validator
docker compose logs -f fhir-validator
docker compose ps
docker compose down

Required env for app API validation:
FHIR_VALIDATOR_URL=http://localhost:8080
FHIR_VALIDATOR_REQUEST_TIMEOUT_MS=150000

----------------------------
git status

git push origin medassist
